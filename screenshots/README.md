## Taking Screenshots

To capture screenshots for the Play Store listing:

1. **Device**: Use a Pixel 8 Pro or similar flagship
2. **Resolution**: 1080 x 2400 pixels
3. **Theme**: Dark (default)
4. **Data**: Populate with realistic practice data
5. **Content**: Show populated screens, not empty states

### Steps

1. Build and run the app
2. Create some practice history (practice 10+ characters)
3. Complete a few sessions to show statistics
4. Navigate to each screen
5. Take screenshot (Power + Volume Down)
6. Transfer to this directory

## Image Requirements

### Phone Screenshots
- **Minimum**: 2 screenshots
- **Maximum**: 8 screenshots
- **Aspect Ratio**: 16:9 to 9:16
- **Format**: PNG or JPEG

### Feature Graphic
- **Size**: 1024 x 500 pixels
- **Format**: PNG or JPEG
- **Content**: App name, tagline, key features

### App Icon
- **Size**: 512 x 512 pixels
- **Format**: PNG (32-bit)
- **Background**: Not transparent

## Play Store Assets

Additional assets needed for Play Store listing:

1. **App Icon**: 512x512px PNG
2. **Feature Graphic**: 1024x500px PNG/JPEG
3. **Phone Screenshots**: 2-8 screenshots
4. **Tablet Screenshots**: Optional, 7" and 10"
5. **TV Banner**: Optional, 1280x720px
6. **Wear Screenshots**: N/A (not a Wear OS app)

## Optimization Tips

- Use consistent lighting/background
- Show the app in its best state
- Highlight unique features
- Include diverse content
- Keep text readable
- Avoid personal information
